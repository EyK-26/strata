## #241 root cause and deterministic correction

The failed candidate `001fb8b` also passes its full gate in an isolated checkout (2,369 source cases, unchanged skips, 34 E2E cases). That pass is not the diagnosis. A native transport stress probe instead encounters a listener allocated numeric port 54329: IPv4 requests reach an already existing SSH-forwarded Postgres service and reset, while the owned Bun response is reachable over IPv6. A controlled two-listener experiment then reproduces the exact 401 with no credentials or auth implementation involved. An owned IPv4 listener returns `other-ipv4-service`/401; the original packed generated helper serves `/health` on the same numeric port on another interface, but its fixture guesses `127.0.0.1` as the authority. The client receives the other service's 401 while the owned handler serves 200. The historical failed log did not capture its numeric address or peer body, so the identity of that earlier unrelated service cannot be reconstructed; the listener/client mismatch is deterministically reproduced on the exact packed candidate, rather than inferred from later passing suites.

The generated helper now forwards optional typed native listener options, and generated config/startup supports an optional `HOST` and reports the actual server URL. Defaults, public-host tenancy, auth and production/staging guards are unchanged. Owned generated/security/OIDC/SAML/CLI and neighboring native HTTP fixtures bind explicitly to the same literal loopback address their clients use. No auth assertion/status is relaxed and no test is skipped/retried as remediation. The new mandatory packed E2E case keeps an unrelated IPv4 401 service live, proves the same address/port cannot be stolen, and proves a fresh owned listener serves the exact health body. Diagnostic direct-handler and independent HTTP-client probes remain failure-only. The corrected unfiltered E2E run passes all 35 cases; the adjacent native HTTP/preflight/metrics/tenancy/HTMX/transaction/drain suite passes 41 cases with its one pre-existing macOS/Linux reusePort skip. Full host/clean CI remain required before the held release is promoted.
