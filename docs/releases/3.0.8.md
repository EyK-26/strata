# Strata 3.0.8

Fix app generation from the published `create-strata` and `@getstrata/starter`
packages. Version 3.0.7 could fail with `ENOENT` while looking for templates:
discovery still required a copied source directory removed during the refactor.
The generator now recognizes the retained TypeScript configuration template and
finds the bundled templates correctly.

Both generator packages must now install from their tarballs and generate API and
hybrid apps outside the repository during CI and release validation. These checks
cover base templates, bootstrap generation, dependency versions and browser assets.

All five packages advance together to **3.0.8**. Start new projects with
`bunx create-strata@3.0.8 my-app`. This patch introduces no additional runtime API or
database migration changes relative to 3.0.7. For upgrades from earlier versions,
retain the [3.0.6 framework upgrade instructions](3.0.6.md).

The fix passed both packed-generator checks, 59 generator/template regression tests,
type checking and formatting. Restoring the old resolver made the new package check
fail, confirming that it detects this regression. With the corrected generator,
the published 3.0.7 runtime also passed a SQLite hybrid authentication journey
covering migrations, startup, registration, verification, password reset and MFA.
That runtime check does not claim to test unpublished 3.0.8 artifacts.

After merging PR #413 and reviewing CI, tag the intended merged commit as `v3.0.8`
to release. Release preparation does not create a tag or publish packages.
