# HiroApp retirement

HiroApp is no longer the framework runtime or contributor Docker application. Its tracked application directories and regeneration script have been removed. Legacy preset IDs remain supported generator layer maps, without checked-in app copies. Product dogfood lives in [strata-shop](https://github.com/EyK-26/strata-shop); framework acceptance generates isolated apps from the current starter and candidate packages.

See [GENERATED-APP-ACCEPTANCE](GENERATED-APP-ACCEPTANCE.md) for preserved assertion inventories and staged validation, and [TESTING](TESTING.md) for current contributor commands. The old `hiroapp:fresh`, `hiroapp:dev`, root `dev`/`start` and Compose app/worker commands are retired.
